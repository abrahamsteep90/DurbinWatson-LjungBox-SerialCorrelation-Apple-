# Durbin-Watson, Ljung-Box, Serial Correlation (Apple)

Using the `statsmodels` package, this notebook applies the Durbin-Watson and Ljung-Box tests to a year of Apple stock returns to check for serial correlation, and discusses the result against the Capital Asset Pricing Model (CAPM) and Arbitrage Pricing Theory (APT) with references to Treynor, Sharpe, Lintner, Banz, and Basu.
